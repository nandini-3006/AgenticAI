1. LangChain LLM Chain
# LangChain LLM Chain

Built my first LLM pipeline using LangChain.

Instead of calling the model directly, I learned how prompts, language models, and output parsers can be connected into a reusable chain.

### What I learned

- Building LLM pipelines
- Prompt engineering basics
- Chaining components using LCEL
- Parsing model responses
2. LangGraph Chatbot
# LangGraph Chatbot

A simple chatbot built to understand how LangGraph manages AI workflows.

The chatbot classifies a user's message before deciding how to respond, introducing the idea of state-driven execution.

### What I learned

- Graph-based AI workflows
- State management
- Nodes and edges
- Sequential execution

4. PDF RAG Chatbot
# PDF RAG Chatbot

Built a chatbot that answers questions from a PDF instead of relying only on the model's knowledge.

This project helped me understand the complete Retrieval-Augmented Generation (RAG) workflow.

### What I learned

- Document chunking
- Embedding generation
- Semantic search
- Context-aware response generation
5. Multi-Agent AI Travel Planner
# Multi-Agent AI Travel Planner

A practice project to understand how multiple AI agents can collaborate to solve a single task.

Instead of one model doing everything, different agents planned, researched, and generated the final itinerary.

### What I learned

- Agent-based workflows
- Tool calling
- Shared state
- Multi-agent collaboration
- Agent orchestration using LangGraph
